# Sol 6.1への02更新確認

取得日: 2026-09-30。対象正本: [02_models.md](../../shared/runbooks/02_models.md)。

[OpenAI公式モデル文書](https://developers.openai.com/api/docs/models/gpt-6.1-sol)でID・料金・context・effortを確認して02へ反映した。Codexのローカルモデルcatalogでも`gpt-6.1-sol`と`low`以上のeffort対応を確認した。順位と役割別effortは維持した。

## Jevの読解確認

[TypeSafe公式API](https://docs.typesafe.ai/api)の`POST /v1/systemone`へ更新後の02全文を渡し、4つの独立したchoice質問を一括送信した。応答モデルは`jev-1.13.0`。選択肢は02の役割別候補から生成し、各質問に任務と仮定した利用枠を明記した。実利用枠の取得や子の起動はしていない。

Codex週次使用率65%、均等ペース50%（1.3倍）を共通の仮定にした。

| 仮定 | 期待 | 実選択 | 選択確率 / confidence |
|---|---|---|---|
| 仕様固定済み実装、Claude Code利用可 | Claude Code / opus | Claude Code / opus | 0.93 / 0.92 |
| 反証、Claude Code利用不可、Grok Build利用可 | Grok Build / grok-4.7 | Grok Build / grok-4.7 | 0.92 / 0.89 |
| 反証、Claude Code利用不可、Grok Build枯渇、Cursor利用可 | Cursor / grok-4.7 | Codex / gpt-6.1-sol | 0.46 / 0.34 |
| 仕様固定済み実装、Claude Code枯渇、Codex利用可 | Codex / gpt-6.1-sol | Codex / gpt-6.1-sol | 0.53 / 0.41 |

新しいSol IDの選択は確認できた。Cursor優先条件は期待と不一致だった。各条件1回だけの観測であり、安定性やモデル性能の比較を示さない。今回のモデル世代更新では、既存のハーネス選択規則や選定実装は変更していない。
