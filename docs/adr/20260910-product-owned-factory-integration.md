# 製品公開後の工場統合の担当と受入

日付: 2026-09-10。状態: 採用。

オーナーの開始指示に基づき、製品担当の公開・単体検証の結果を受けてdotagentsの統合を行う。対象はdotagents repo、工場所有の配置・設定・更新予約・報告と公式入口の実行だけとする。製品repoの修理・公開は担当へ返し、製品の不足を工場の内部状態操作・独自手順で補わない。

製品の公開契約、工場の変更、実端末への導入、fresh reportとBugHubの受入が連鎖するため統括レーンとする。工程は既存の`docs/plan_product-owned-setup-20260909.md`を継続し、Latticeの別工程を変更しない。

工場の公式入口への切替と本番受入は親が裁定するF作業、確定した変更の実装はA作業とする。製品記録の抽出は読取り専用で並列に進め、同一repoの書込みと共有AI設定の本番反映は直列にする。現行機能、4 AIへの提供範囲、日次・週次の頻度、Spotterのproject選択、工場Gantt hookを維持する。

関連focused試験が成功した後に最終通し試験を行う。公開済み製品の正規入口をAitermの永続PTY内のSSHセッションから現役端末へ順番に実行し、製品公開probeと工場reportの到達で判定する。未公開、依存待ち、未実施、失敗は完了へ丸めない。変更は対象限定commitで保存し、mainへpushして各端末へ届ける。
