# Jev上流製品の工場配布と責任境界

2026-09-21の依頼を受け、jev-ultrafastとagent-desktopを第三者管理として一撃展開へ加える。導入・更新は上流最新版の公式入口を呼ぶ。上流本体・操作ループ・OS対応・製品設定・不具合修正は上流が所有し、工場のpatch・独自操作wrapper・旧版への自動降格は採用しない。

dotagentsは公式導入・更新呼出し、工場キーの配布、公開versionと実行結果の記録を所有する。ServerManagerはBugHubの受信・保存・表示・配備を所有する。固定集合の既存wireを変更せず、新wireの受信を先に公開してからclientを切り替える。これが複数repoの書込み調整に当たるため統括レーンとする。親による直接実装とread-only反証で進め、書込みWorkerは使わない。

agent-desktopは上流実装のあるMacだけを導入対象とする。Windows/Linux対応を工場で補作しない。導入・定期報告でGUIやdaemonを起動せず、導入済みとGUI実行確認を区別する。

受入は導入の再実行、失敗伝播、OS別対象、新旧wire互換、公開結果の保存・表示、秘密非出力、関連テストと各repo必須テスト、対象限定commit・pushで判定する。全端末への即時再展開は行わず、Macを先行確認に使う。既存の他作業dirtyは保持する。
