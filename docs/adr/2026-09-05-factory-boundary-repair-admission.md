# 工場の責任境界修理の着手裁定

日付: 2026-09-05。状態: 決定。

オーナーの修理指示を受け、BellTeamのホーム逸脱とdotagentsの配布・CI・案内の確認済み欠陥を修理する。
複数repoの書込みを調整するため統括レーンを適用する。設定生成先の変更と本番反映を含むためriskはhigh、behavior-changeとする。
修理の所有者は状態の所有repoであり、BellTeam固有規範を工場へ合成しない。
親が書込み・受入・本番反映を担当し、独立調査は読取専用とする。新しいLattice工程管理とwriter並列は採用しない。
目的、既知の失敗、受入範囲は[修理記録](../evidence/2026-09-05-factory-boundary-repair.md)で宣言した。
