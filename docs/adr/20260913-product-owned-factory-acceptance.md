# 製品所有の導入入口と工場統合の最終受入

2026-09-13。判定者: Belle。対象は[製品所有の導入入口へ戻す改修](../plan_product-owned-setup-20260909.md)。

## 判定

受入完了とする。製品の欠陥は所有repoで修理・公開し、dotagentsは標準入口の呼出し、公開結果の記録・配送、自身の配置・予約を担当する実装へ戻した。製品結果の追加検査・再集約で成否を作り替える処理は撤去した。

根拠は[コード受入と別ベンダー反証](../evidence/20260913-product-result-ownership.md)と[4端末の受入](../evidence/20260913-product-owned-four-host-acceptance.md)。公開済み製品の公式導入、4端末の配送receiptとWebUI表示、Windowsの工場設定確認・予約更新、最終公開CIの3 OS成功を確認した。

Windowsのnpm更新で一度発生したファイルロックは、公式更新と登録タスクの再実行で復旧した。保持プロセスは未特定であり、恒久修理したとの判定はしない。この観測を隠さず、原因不明の製品変更や工場での補正を追加せずに、復旧後の実行結果を受入した。

## 正典と保全

既存の責務境界を実装へ戻す変更であり、新たな規範やオーナー承認待ちは追加しない。統合契約台帳と工場reporter runbookへ反映し、工程正本を完了へ更新した。Macの既存Cursor変更2件、rabbitの読取許可差分、各製品の所有外設定を保持した。
